## Important Rules

- **Do NOT push changes to GitHub unless explicitly asked.** Only commit and push when I say so.
- **Before editing any file, save a backup copy** with a timestamp in the filename so I can revert if needed. Example: `index.html` → `index.html.bak.2026-07-28`
- **ALWAYS backup before editing HTML or JS files.** Any time you touch a `.html` or `.js` file, create a backup copy with the current date and time in the filename, e.g. `index.html` → `index.html.bak.2026-10-03-1430` and `support.js` → `support.js.bak.2026-10-03-1430`. Never edit a file without first saving a backup.
